# 🎯 TODO Application with Command Pattern (TypeScript)

### Домашнє завдання до Теми 10 — Поведінковий патерн Команда (Command)

## 📌 Мета роботи

Реалізувати консольний TODO-застосунок із використанням поведінкового патерну **Command**, де кожна дія над задачами оформлена як окремий об'єкт-команда.

Застосунок підтримує:

* ➕ додавання задач;
* ✏️ оновлення задач;
* ✅ зміну статусу виконання;
* 🗑️ видалення задач;
* ↩️ скасування дій (`undo`);
* ↪️ повторне виконання дій (`redo`).

---

## 🧠 Застосований патерн

### 🎮 Command (Команда)

Патерн **Command** інкапсулює кожну дію у вигляді окремого об'єкта.

У проєкті реалізовано такі команди:

* `AddTaskCommand`
* `RemoveTaskCommand`
* `UpdateTaskCommand`
* `CompleteTaskCommand`

Кожна команда реалізує методи:

```ts
execute()
undo()
redo()
```

Завдяки цьому будь-яку дію можна виконати, скасувати або повторити.

---

## 🔄 Як працює undo / redo

Усі команди виконуються через:

```ts
CommandHistory
```

Виконання команди:

```ts
history.executeCommand(command);
```

Скасування останньої дії:

```ts
history.undo();
```

Повторне виконання:

```ts
history.redo();
```

Історія команд автоматично зберігається та дозволяє послідовно переміщатися назад і вперед по виконаних діях.

## 📋 Демонстрація роботи

Після запуску застосунок виконує наступну послідовність:

1. ➕ Додає задачу
2. ✏️ Оновлює задачу
3. ✅ Позначає як виконану
4. 🗑️ Видаляє задачу
5. ↩️ Виконує серію `undo`
6. ↪️ Виконує серію `redo`

Приклад виводу:

```text
--- Після додавання задачі ---
[ Task ]

--- Після оновлення задачі ---
[ Updated Task ]

--- Після позначення як виконаної ---
[ Completed Task ]

--- Після видалення задачі ---
[]

--- Після undo видалення ---
[ Task ]

--- Після undo виконання задачі ---
[ Task ]

...

--- Після redo видалення задачі ---
[]
```

## ⚙️ Основні компоненти

| Компонент         | Призначення                            |
| ----------------- | -------------------------------------- |
| `Task`            | Модель задачі                          |
| `TaskList`        | Зберігання та управління задачами      |
| `Command`         | Базовий інтерфейс команди              |
| `AbstractCommand` | Абстрактна команда з базовим `redo()`  |
| `CommandHistory`  | Історія виконаних команд               |
| `TaskManager`     | Центральний сервіс управління задачами |
